# @moonshot/types

Shared TypeScript **contracts** for API, KDS, order-ahead, admin, and tooling.

Runtime domain logic (open-hours helpers, KDS prep derivation, loyalty discount math, menu template catalogues, POS adapters, socket/HTTP path constants, etc.) lives in [`@moonshot/domain`](../domain/).

Architecture and sequence diagrams: [`../docs/`](../docs/) (start with `docs/README.md` → `current/flows.md`).
