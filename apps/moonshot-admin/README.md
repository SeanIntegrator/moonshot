# @moonshot/admin

Café owner dashboard: **Vite + React + TypeScript + MUI** for fast CRUD and data-dense screens.

## Env

- `VITE_API_URL` — API origin only (e.g. `http://localhost:3000`). Do **not** include `/api/v1`.

Pre-seeded admins are created via `@moonshot/api` `scripts/bootstrap-admin-user.ts` (see `apps/moonshot-api/.env.example`).
